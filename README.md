# 메덩골정원 웹사이트 리디자인 (포트폴리오)

학원 웹디자인 과정 개인 포트폴리오 작업입니다. 상업용이 아니며, 공식 MÉDONGAULE(메덩골정원) 사이트가 아닙니다.
사진·로고의 저작권은 각 소유자에게 있습니다. 예약 화면은 시연용으로 실제 예약·결제가 되지 않습니다.

## 파일
- `index.html` — 사이트 전체 (HTML·CSS·JavaScript 한 파일)
- `img/` — 사이트에서 쓰는 사진·로고 (43개)

## 보는 방법
- `index.html`을 브라우저(크롬 권장)로 열면 됩니다.
- 글꼴(Pretendard)은 인터넷(cdn.jsdelivr.net)에서 불러오므로 인터넷이 연결되어 있어야 디자인 그대로 보입니다.
- 같은 탭에서 새로고침하면 로딩 화면을 건너뛰고 인트로부터 나옵니다. 새 탭으로 열면 로딩부터.

## 배포 (예: GitHub Pages, Netlify)
- 이 폴더 전체(index.html + img)를 그대로 올리면 됩니다.
- 배포 전 권장: `<head>`에 `<meta name="robots" content="noindex">` 추가 (공식 사이트와 헷갈리지 않게)
