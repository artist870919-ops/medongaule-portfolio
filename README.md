# 메덩골정원 웹사이트 리디자인 (포트폴리오)

웹디자인 수업 과제로 만든 비상업 리디자인 시안입니다. 메덩골정원(MÉDONGAULE) 공식 웹사이트가 아닙니다.
사진과 로고의 권리는 각 권리자에게 있습니다.

## 여는 방법
- `index.html`을 브라우저로 열면 됩니다. `img` 폴더가 `index.html`과 같은 위치에 있어야 사진이 보입니다.
- 글꼴(Pretendard)은 인터넷에서 불러오므로 인터넷이 연결된 상태에서 열어 주세요.
- 파일을 바로 열었을 때(file://) 로딩 화면 워드마크가 안 보일 수 있습니다. 웹서버나 배포 주소(GitHub Pages 등)로 열면 정상입니다.

## 구성
- `index.html`: 화면, 스타일, 동작 코드가 모두 들어 있는 한 파일
- `img/`: 사진·로고 45개
